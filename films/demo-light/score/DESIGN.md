# 《光与弦》配乐：设计、接口、拆解

唯一的时间来源是片目录的 `timeline.json`（90 BPM，4/4，一拍 16 帧 = 0.6667 s，一帧 41.67 ms；9 小节 = 576 帧 =
24.000 s，其中 9.1–10.1 是画面纯黑的音乐尾巴）。本文件先于代码写成，实现后按实测改过（第 6 节）。

## 1. 调性与材料

- **D 大调**，旋律材料只用 D 宫五声（D E F# A B），和声加九音、挂四，不用叮当的小二度。
- 和声走向（每次换和弦都是一个 `chord` 事件）：

  | 位置 | 和弦 | 作用 |
  | --- | --- | --- |
  | 1.1–3.1 | Bm（B D F#） | 暗处：只有拨弦的脉冲和一点低处的弦 |
  | 3.1 H1 | D add9 | 光聚成字：第一次大调，明亮地落下 |
  | 4.1 | G add9 | 下属，让出一点空间（energy 0.4） |
  | 4.4 | A sus4 | 属挂四，4.4 起渐强、加速，推向 5.1 |
  | 5.1 H2 | Em9（E G B D F#） | 弦放开，字化为光；不解决到主和弦，留着往前走 |
  | 6.1 | A sus4 | 光丝汇聚，悬着 |
  | 7.1 H3 | D add9（宽声位） | 挂留音 E → F# 解决，落成一枚光斑 |

- **光的动机**：F#5 – E5 – D5 – A4（下行，「光落下」），3.3–4.3 第一次出现，7.3–8.3 在片尾重现、更稀。
- **节奏密度的弧线**（画面读 `pulse`）：P1 八分 → 4.4 十六分的上行 → 第 5 小节十六分（飞散）→ 第 6 小节八分（汇聚）
  → 第 7 小节四分 → 第 8 小节二分 → 9.1 停。

## 2. 逐段

| 位置 | 层（stem） | 写法 |
| --- | --- | --- |
| 1.1–9.1 | `ambience` | 极弱的 Wind（无哨音、很暗），1.6 s 淡入；房间的空气 |
| 1.3–2.4 P1 | `pulses` | 闷拨 Pluck 的八分音符，左低右高交替（左 B3 D4 E4，右 F#4 A4 B4），力度与亮度随 energy 慢慢起来；每一下是一个 `pulse` 事件（带 `light` 0..5 = 音高从低到高的序号） |
| 2.1–3.1 | `strings` | 弱音器 + 指板上（sordino、tasto）的 Bm 低声部，pp 渐强，吸一口气 |
| 2.4–3.1 | `swell` | 反向混响涌起（D 大三和弦源，plate），峰值在 3.1 前约 2 帧（光点聚向中心） |
| 3.1 H1 | `harp` `felt` `bells` `strings` `sub` | 拨弦从 A5 往下扫成 D add9（第一个音正落在 3.1，之后每 1/32 拍一个）；毛毡琴 D add9 和弦（两者在 4.1 换和弦时止音）；玻璃钟 D6 一声（字亮），3.2 再一声 E6（小字晚一拍亮）；弦乐打开（不加弱音器）；次低频 D1 进入 |
| 3.3–4.3 | `felt` | 光的动机（毛毡琴，止音） |
| 4.1 / 4.4 | `strings` `sub` | 连奏换到 G add9，4.4 换到 A sus4 并渐强到 5.1 |
| 4.4–5.1 | `harp` `air` | 拨弦十六分上行 A4 D5 E5 A5（加速）；气流从左扫到右，峰值在 5.1 后约 2 帧（镜头穿过字面） |
| 5.1 H2 | `strings` `impact` `sparkle` | 渐强的弦在 5.1 放开（0.12 s 收弓，混响带走尾巴）；低频轻击（Boom E1 + 毛毡大鼓）正在 5.1；Sparkle 从 D5 往上散开两拍（字化为光） |
| 5.1–6.1 | `pulses` | 十六分音符，左右交替，Em9 的分解；力度随 energy 从 0.85 往 0.6 落 |
| 5.1+0.5–9.1 | `strings` | 指板上的软垫：Em9 → A sus4 → D add9，连奏 |
| 6.1–7.1 | `taut` `choir` `pulses` | 一根被拉紧的光弦（TautString）从低 45 音分处升到 A3，正好在 7.1 前到音；远处合唱 oo 渐入（A sus4）；脉冲变成八分 |
| 7.1 H3 | `felt` `bells` `choir` `strings` `sub` | 宽的 D add9：毛毡琴低音区和弦、玻璃钟一声很轻的 D6、合唱 E4 → F#4 解决、低音提琴 D2 加入、次低频 D1；脉冲变成四分（D4 A4 F#4 A4） |
| 7.3–8.3 | `felt` `pulses` | 光的动机重现（更稀），脉冲变二分，8.3 之后不再有脉冲 |
| 6.2–9.1 | 主推子 | 6.2 → 7.1 让出 4 dB（片尾比中段安静得多，energy 0.35 → 0.1），8.2 → 9.1 再跟画面的淡出往下压到 −12 dB |
| 9.1 CUT | 全部干声 | `s.cut("9.1", "10.1", tails=True)`：干声在这一帧停，混响母线不切，尾巴自然衰减到 10.1；`hall` 的输入 8.2 → 9.1 骑下 8 dB（切点之后剩下的尾巴比音乐低一截，听得出是一刀切），`long` 的输入 7.4 → 8.3 关上，免得尾巴拖过文件末尾 |

空间：`room`（0.45 s，近）、`hall`（2.8 s，主空间）、`long`（cathedral 4.5 s，只给 H1、H2 和片尾的长音）。分轨名
`reverb_room / reverb_hall / reverb_long`（自检按 `reverb_` 前缀认母线）。

## 3. 同步点怎么落

| 同步点 | 画面 | 音乐（实测项） |
| --- | --- | --- |
| P1 1.3–2.4 | 远处光点明灭 | 12 个八分音符脉冲，`events.json` 里每个都正好在八分网格上（≤ 1 ms，无人性化偏移） |
| H1 3.1（硬） | 光聚成字 | 拨弦与毛毡琴的起音在 3.1 ±10 ms；钟在 3.1；涌起峰值在 3.1 前 1–3 帧 |
| H2 5.1（硬） | 穿过字面，画幅打开 | 弦乐分轨在 5.1 之后 3 帧内降 10 dB、6 帧内降 20 dB（放开）；低频冲击起音 0–1 帧；气流峰在 5.1 后 0–4 帧 |
| H3 7.1（软） | 汇聚成一枚光斑，片名淡入 | 光弦到音、合唱解决、钟一声；脉冲从八分变四分 |
| CUT 9.1（硬） | 切黑 | 干声分轨在 9.1 之后 < −120 dBFS；混响分轨还在响；尾巴在 10.1 前降到 −60 LUFS 以下；文件正好 24.000 s |

## 4. 接口：`out/music/events.json`

画面引擎读它（`beats` 与 `events`）；格式与 filmsynth 原来的相同，字段说明见 [`music/filmsynth/README.md`](../../../music/filmsynth/README.md) 第 8 节，这部片与 demo-paper 两份 `events.json` 的逐字段对照见 [`docs/TIMELINE.md`](../../../docs/TIMELINE.md) 第 10 节。

- `beats`：37 个数（1.1 … 10.1），与网格误差 ≤ 1 ms。
- `markers`：时间线的 `P1 H1 H2 H3 CUT`（`kind: hard_sync | soft_sync`；P1 带 `to: "2.4"`），外加 `swell_peak`、
  `air_crest` 的设计位置。
- `events: [{t, frame, type, pos, ...}]`，按时间排序：
  - `pulse`：每一下脉冲。`shot`（`S01` / `S03` / `S04`）、`side`（`L` / `R`）、`div`（音符时值，与原格式相同：
    8 = 八分、16 = 十六分、4 = 四分、2 = 二分）、`vel`（0..1）、`bright`（0..1，画面可以映射亮度）、`pitch`；S01 的还带
    `light`（0..5，音高从低到高的序号，画面可按自己的光点数取模）。S01 12 个（1.3 … 2.4+0.5，八分）、S03 23 个
    （5.1+0.25 起十六分 15 个，6.1 起八分 8 个）、S04 6 个（7.1–7.4 四分、8.1 与 8.3 二分）。
  - `run`：4.4 的拨弦十六分上行（S02，4 个，`n` 0..3、`pitch`），镜头加速时可以用。
  - `chime`：3.1（`line: 1`，大字）与 3.2（`line: 2`，小字）的钟，7.1（`line: 0`）一声很轻的落点。
  - `chord`：每次换和弦（`chord` 名，如 `"D add9"`；H1 带 `id: "H1"`）。
  - `motif`：光的动机每个音（`pitch`、`n` 第几个音）。
  - `release`（5.1 弦放开）、`impact`（5.1 低频冲击）、`sparkle`（5.1，`beats: 2`）、`taut`（6.1，`to: "7.1"`）、
    `land`（7.1）、`cut`（9.1，`tails: true`）。
- `curves.energy`：时间线的 energy 曲线按 0.05 s 采样（画面与配乐共用的意图）。
- `measured`：自检写入的实测（同步表、干切、响度）。

## 5. 拆解

1. `score.py`：`build(tl)` 建谱（总线、音轨、音符、事件，顺序固定：音符种子取决于轨名与音符顺序），`main()` 渲染到
   `out/music/`。
2. `selfcheck.py`：调 `filmsynth.check` 的通用检查（响度、真峰值、ffmpeg 交叉、事件表、网格、干切、和声、energy
   跟随、分轨平衡、图），加本片专有的判断（第 3 节）；`--determinism` 用两种进程数各渲染一次并逐样本比较。
3. 实测后调推子、涌起位置，写回第 6 节。

## 6. 实现时相对上面计划的改动

- **电平跟着 energy 走。** 第一版按乐器校准值配推子，片尾（7.1–9.1，energy 0.35 → 0.1）反而是全片最响的一段
  （1 s 响度比 5.1 还高，energy 跟随的相关只有 0.53）。按每拍的分轨响度逐层调：P1 的脉冲音符级 −7 dB；H1 的毛毡琴、
  拨弦各降 4 dB 左右，3.1–5.1 的弦乐降 6 dB、渐强的顶从 0.88 改 0.82；第 6 小节的光弦不再渐强（`(0.46, 0.5)`），
  合唱 6.1 从 0.04 进到 0.3；片尾合唱、弦乐垫、毛毡琴低音和弦都压低，再加主推子 6.2 → 7.1 让出 4 dB。结果相关 0.94
  （Spearman 0.97），拟合 `L ≈ −29.9 + 26.4·energy` dB，残差均方根 2.0 dB。
- **干切听得出来。** 第一版 9.1 前后混音只差 5.6 dB（hall 的尾巴太大）；hall 的输入 8.2 → 9.1 骑下 8 dB 后差 12.6 dB。
- **被盖住的层。** 自检的「事件在其后 250 ms 比其余混音高多少」报出：片尾的低音脉冲（D3 A3）在 300–3000 Hz 比其余低
  11–14 dB → 移高八度；3.2 的钟（A5）在 4–12 kHz 比其余低 12 dB → 换成 E6、力度 0.48；4.4 的拨弦上行比其余低 23–33 dB
  → 音符级 +12 dB、气流 −2 dB；玻璃钟整体 +8 dB（3.1 那一声在 4–12 kHz 与其余持平，听得出是一声轻钟）。
- **H2 的低频冲击**降 3 dB：限幅器在 5.1 的最大压缩量从 5.4 dB 降到 4.3 dB。
- **和弦表的检查**报出 3.4 的动机音 E5 写了 1.8 拍、拖进了 4.1 的 G add9：改成 1 拍。H1 的拨弦与毛毡琴原来让它
  一直响，改成在 4.1 止音（换和弦时不糊）。
- **S02 的上行**原来也记成 `pulse`（`side: "C"`），改成单独的 `run` 类型：画面的 `pulse` 只在 S01 / S03 / S04 出现。
- **测量方法。** 脉冲的起音用 2 kHz 以上、1 ms 窗的最大 3 ms 上升（十六分音符时前一下还在响，「达到峰值 −20 dB」的
  办法会落在窗口起点）；弦乐「放开」用「从 5.1 前 100 ms 的电平降 10 dB / 20 dB 用了几帧」判（释放 0.1 s 加上
  每个演奏者 ±25 ms 的偏差，最陡的下降在 +120–160 ms，不适合当作同步时刻）。
